# ❄️ Hunker Bunker v2.1.0-Beta — Sprint 21 Release Notes

Sprint 21 is the largest Hunker Bunker world and platform update yet. This
release rebuilds the expedition around a streamed five-ring labyrinth, makes
the bunker faster and more destructible, brings the full menu and settings
flow to Steam Deck controls, and adds a broad presentation pass across doors,
operators, maps, audio, and run telemetry.

## 🚀 Key Highlights

### 🌌 Five-Ring Expedition & World Streaming

- **Radial WFC labyrinth:** Runs now expand through five authored progression
  rings, with camps, hives, mission gates, shortcuts, canyon bands, and the
  Mother Hive placed on a connected tactical route.
- **Deterministic progression gates:** Ring crossings are visible landmarks
  tied to mission progress and validated across thousands of generated seeds.
- **Stronger chunk streaming:** Wider prefetching, stable cache retention,
  staged chunk rebuilding, and safer crash-site spawning reduce unloaded or
  untextured areas while moving through the world.
- **Upgraded tactical map:** Added scanned routes, landmarks, panning, zoom,
  player/home focus controls, controller navigation, and mapping missions.

### 🚪 Destructible Bunker Performance Pass

- **Instanced walls and doors:** Standard walls, damaged walls, door ribs,
  panels, pillars, brackets, vents, and pipes now use pooled instancing to
  substantially reduce draw-call pressure.
- **Per-wall destruction restored:** Projectile damage, tinting, collision,
  and cleanup remain attached to the individual wall section instead of the
  entire shared instance pool.
- **Walkable breaches:** Destroyed walls and repaired/filled terrain no longer
  leave invisible collision behind.
- **Procedural door polish:** Doors appear at room thresholds with corrected
  transforms, smoother hydraulic transitions, atmospheric fades, and new
  biomechanical key art.

### 🎮 Steam Deck, Controller & Accessibility

- **End-to-end menu navigation:** WASD, arrows, D-pad, sticks, Steam Input,
  confirm/back actions, tab switching, focus wrapping, and hover audio now
  operate the title, hero select, settings, polish selector, maps, archives,
  and nested dialogs.
- **Deck-native interaction:** Added browser-gamepad fallback, right-stick
  virtual cursor and scrolling, Steam gamepad text entry, dynamic Deck/keyboard
  prompts, and 3D right-stick aiming.
- **Readable settings:** System Settings now keeps its title and close action
  pinned, centers the focused option while navigating, wraps choices, exposes
  visible scrolling, and uses higher-contrast section headers.
- **Display controls:** Added Steam Deck resolution presets, independent UI
  scale and minimum text size, text speed, colorblind assistance, camera shake,
  remapping, save tools, and fullscreen/display safeguards.

### 🧑‍🚀 Operator, Menu & Run Presentation

- **Rebuilt hero select:** A tighter three-panel loadout console combines the
  route display, operations/records, operator preview, class cards, loadout,
  S.O.U.L. statistics, Steam state, and Initialize action.
- **Suit Polish system:** Added 16 unlockable operator finishes with preview,
  selection, persistence, locked states, and developer unlock support.
- **Profile and roster improvements:** Improved callsign entry/randomization,
  operator telemetry, loadout cards, fabrication links, empty-state handling,
  and long-name containment.
- **Atmospheric title and game-over screens:** Added mist/water ambience,
  stronger selection feedback, improved telemetry hierarchy, and cleaner
  transitions back into the menu.

### 📡 Narrative, Camps & Missions

- **LineDirector:** Reactive Mothership and Director commentary now passes
  through a context-scored arbiter with tagged pools and cooldown control.
- **Living survivor camps:** Workers track individual state, faction verbs feed
  camp interactions, and bonding/quest outcomes connect to the wider run.
- **More authored exploration:** Added room themes, wreckage and lore beats,
  black-box routes, reactive cliff exploration, camp cues, collectibles, and
  environmental storytelling assets.

### 🎵 Audio, Art & Content Packaging

- Added original camp cues, interactive song interstitials, and a validated
  **43-track original soundtrack** package.
- Expanded biomechanical doors, cave and camp props, enemy/suit animation
  sources, cinematics, store capsules, and runtime texture coverage.
- Retail builds now audit required media and exclude store-only/source artwork
  while ensuring runtime textures, doors, cinematics, and audio are packaged.

### ⚙️ Steam, Builds & Reliability

- Added native Linux/Steam Deck and Windows depot packaging with root-level
  launch executables and preserved Linux executable permissions.
- Hardened Steam Input manifests, cloud/save handoff, Inventory/Vault assets,
  leaderboards, achievements, soundtrack upload, and beta-branch release tools.
- Added cross-platform presubmit checks, generated-report freshness audits,
  CodeQL analysis, Lighthouse, coverage artifacts, dependency audits, and Steam
  package verification.
- The current automated suite covers **1,108 passing tests across 144 files**,
  including multi-thousand-seed world-generation stress checks.

## 🛠️ Fixes & Stability

- Fixed unloaded tile traversal, canyon/cliff walkability, missing corridors,
  scene leakage during door transitions, and unsafe spawn timing.
- Fixed shared wall-pool destruction, black damage tinting, stale collision,
  door-rib rotation, double-closing transitions, and hidden-scene masking.
- Fixed hero-select focus flow, settings scrolling, text-input capture, selected
  item stacking, long UI labels, callsign overflow, and return-from-run state.
- Fixed SteamOS sandbox launch, missing executable depot layouts, stripped Unix
  permissions, Windows path/line-ending CI failures, and stale generated audits.

## 📦 Upgrade Notes

- Steam Deck/Linux installs use the native `hunker-bunker` launcher at the
  depot root; Windows uses `hunker-bunker.exe` at the depot root.
- Existing saves remain supported through the profile/save bridge.
- This remains a beta build. Large procedural and platform changes should be
  reported with the run seed, platform, input device, and reproduction steps.
