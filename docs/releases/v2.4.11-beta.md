## Steam Deck input

- **Tactical map (GAP-GP-01).** The map is a menu focus root and asks Steam Input for the menu action set while open. Map toggles are debounced across the gameplay, menu and map polling paths, and the View/Start press that opened the map must be released before it can close it — previously the map's own poll read the still-held button as a close on its first frame.

## Guidance home

- **Extraction (GAP-GP-04).** Completing a mission objective, or the third milestone boss falling, tracks a priority-1 extraction objective on the player's own crashed ship, adds an airlock landmark to the map and radios the player home (7 locales). The sector-purged line plays once per run.

## Performance

- **Transient effects (GAP-RN-01).** Damage-pip text textures are drawn once per label and shared (48-label cap); rain splashes, impact shockwaves and frost shockwaves each share one ring geometry (the frost ring keeps its own shape). The effect disposer skips resources flagged `userData.shared`. The 64-effect cap now also holds in the per-frame update.

## Collision

- **Invisible walls (GAP-RN-02).** Props were fixed in `8bd955d` (a hidden source collides only while its 3D model is mounted and visible). Crashed-ship modules replaced by a 3D model had lost their collision entirely; they now collide while that model is shown.

## Co-op

- **Boss fights (GAP-MP-01, partial).** A guest's hit on a boss used to land only on the guest's copy and was erased by the host's next snapshot, so guests could not hurt bosses. Boss hits now report to the host like any enemy hit, and a peer's fight HP — and therefore its phase — follows the host. Networked hits no longer pick up the receiving player's loadout multiplier. Boss adds and phase radio lines still run per client.

## World generation

- **Reachability (GAP-GP-07).** Route topologies carry a reachability result built on `mazeTiers`' disjoint-route search, and `validateRadialMazeExpedition` rejects a plan whose Queen chunk is unreachable. A second disjoint route is reported but not required: generation-2 gates are deliberately route cut points.

## Menus

- **Modals take focus when they open.** About, the dev console and Operator Polish opened by removing `hidden` while their markup kept `aria-hidden="true"`, so every control counted as hidden: nothing was focused and screen readers skipped the modal. A focus root's `aria-hidden` now follows its `hidden` class.
- **Every control is reachable by controller.** Up from the top row of Operator Polish reaches its close button; the Homebase callsign field and randomize button are reachable from the polish slot. Both failed on `mothership` too.

## Desktop shell

- `npm run electron:dev` loads `electron-debug` (DevTools detached, F12 / Ctrl+Shift+I, F5 / Ctrl+R; `HB_DEVTOOLS_OPEN=0` keeps it closed) and installs Chrome Web Store extensions listed in `HB_DEVTOOLS_EXTENSIONS`. Packaged and Steam builds never load either package; `npm run audit:dependencies` passes again.

## Tests and docs

- **E2E boot helper (GAP-TS-01).** The helper was not broken. The aim-cursor specs had a 120s budget, the same as the helper's own boot deadline, and now get 300s like the gibs spec; the gibs corpse test now kills the enemy it spawned instead of the first one in the world. Run against a dev server without HMR: a watched server reloads mid-test whenever `src/` changes.
- **Browser specs.** The config's per-test budget is 300s (the boot helper alone may take 120s). `bootToTitleSplash` waits for the `title-interactive` boot trace, so specs no longer drive menus while the boot doors are still closing. The menu-reachability audit keeps a nested surface's parent open and stops its arrow presses from committing values (it had been running the debug console's `tp nexus`).
- **Docs (GAP-TS-02).** Playthrough report links are repo-relative; the docs audit tracks `dev/sprint-45`.
