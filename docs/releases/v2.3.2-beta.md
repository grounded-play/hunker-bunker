## Included

- **3D Chest-Mounted Operator Patches**:
  - Attached to operator chest bone (`mixamorig1Spine2` / `mixamorigSpine2`), articulating in real world space with upper-body animations.
  - Mounted snug against the breastplate armor (~5–7cm from spine center), eliminating the previous floating offset.
  - Physical 3D beveled composite backing plate with shadow casting and receiving.
  - Front-side culling and standard Z-buffering depth writes so the patch naturally occludes behind the character's back mesh.
- **High-Fidelity Cosmetic Patch Decals**:
  - Replaced placeholder graphics with custom transparent RGBA decals (Sub-Zero Pioneer `4120`, Radiation Trefoil `4121`, Sporesnail Hunter Crest `4122`, Cyber-Skull Tactical Pin `4124`, Cryo-Phoenix `4125`, plus Victory patches `2000-2002`) in both standard 256×256 and high-res 512×512 inspect formats.
- **Startup Microscopic UI Scaling Fix**:
  - Replaced hardcoded `--vu: 1px` fallback with pure responsive CSS `min()` calculation.
  - Injected synchronous inline metrics token computation on frame 0 before DOM rendering, eliminating the startup 8x visual jump.
- **Mayor Tina Encounter Placement & Locomotion**:
  - Seeded dynamic discovery position along the northbound route (Z -14 through -20, centered at X 9).
  - 180-degree rotation around Y axis facing the approaching player.
  - Preserved operator body detachment, transformation secret, and player locomotion.
- **Co-op Squad-Wipe Handling**:
  - Automated match termination with `squad-wipe` death attribution when both players are downed.
- **Retail Asset Payload Optimization**:
  - Resized bloated 4096×4096 embedded textures to 1024×1024 on two overclock GLBs, reducing payload by 58.45 MiB and restoring strict 2,700 MiB asset budget.
- **Diagnostics & Diagnostics Profiling**:
  - GPU query resets across menu/gameplay phase transitions.
  - Synchronous `world-model:clone` and `world-model:prepare` instrumentation.
- **Main Menu Dialogue Isolation & HUD Polish**:
  - Prevented in-game transmissions and dialogue modals from firing on the main menu showroom loop.
  - Centered tactical HUD, removed emojis, added diegetic translucent backing behind weapons.
