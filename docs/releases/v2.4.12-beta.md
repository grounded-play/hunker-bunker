## 🚀 Key Features & Architectural Upgrades

### 1. Invisible Essentials Phase 4: Pneumatic Transit & Return Network
- **Pure Transit Logic (`src/pneumaticTransit.js`):** Authoritative state machine managing terminal unlocks, combat proximity lockouts (`TRANSIT_COMBAT_RADIUS = 12m`), destination calculation (Sanctuary coordinates `(9, 0, 5)`), and transition sequencing (`idle` → `initiating` → `transit` → `completed`).
- **Interactive In-World Terminal (`src/threeGame.js`):** Arena transit terminal spawns at `(45, 0, 18)` upon defeating the milestone boss via `unlockTransitTerminal()`. Integrated into `getPriorityInteractionCandidates()` within a 2.5m prompt radius with candidate cycling.
- **Combat Interlock Safety:** Rejects transit during active combat encounters (`encounterState?.inEncounter`) or when hostiles are within 12 meters, providing tactile audio/visual lockdown warnings.
- **Tactical Map Landmarks & Breadcrumbs (`src/mapSystem.js`):** Added landmark registration for transit terminals (`registerTransitTerminalLandmark`), nanite bridges (`registerNaniteBridgeLandmark`), and milestone gates (`registerMilestoneGateLandmark`). Computes objective breadcrumbs (`getObjectiveBreadcrumbs()`) from player location to active mission/terminal targets with intermediate waypoints.
