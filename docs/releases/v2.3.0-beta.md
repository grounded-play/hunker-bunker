# ❄️ Hunker Bunker v2.3.0-Beta — Sprint 28 Release Notes

Sprint 28 expands Hunker Bunker into a full 3D visual and mechanical showcase. Featuring a complete 3D asset conversion pipeline with 46 new GLB models (30 community chassis skins and 16 Season 0 / achievement assets), an overhauled Armory with custom class backgrounds, the new Wanderer companion system, native Steam Deck twin-stick aiming, mid-run crash recovery, and engine-level performance budgets.

---

## 🚀 Key Highlights

### 🎨 3D Asset Conversion & Armory Visual Overhaul
- **46 New Runtime 3D Models:** Converted, rigged, and integrated 30 community operator skins (`public/3d/runtime/community/`) across Scout, Tank, and Engineer classes alongside 16 Season 0 weapon, mod, and character GLB models (`public/3d/runtime/new3ds/`).
- **Dynamic Armory Class Theming:** Redesigned the Armory with a clean 3-column layout tailored for PC and Steam Deck displays (eliminating vertical scrollbars). Integrated bespoke atmospheric class background art for Scout, Tank, and Engineer with interactive mouse-orbit 3D model previews and live rig animation mixers.
- **Dynamic NPC & Boss Rigs:** Integrated skeletal animations and dialogue gesture triggers for Aria, Dr. Nahl, Mother Martha, Overseer Kaelen, Queen 00, Val, and corrupted boss variants.

### 🧭 Crash-Site Wanderers & Companion System
- **6 Wanderer Archetype Families:** Introduced the post-level crash-site Wanderer system featuring 6 unique archetype families with bespoke lore questions, branching dialogue, and companion quests.
- **Progression & Oxygen Gating:** Wanderers arrive at the crash site once the bunker's O2 generator is online and at least one milestone boss has been defeated.
- **Active Companions & Passive Buffs:** Befriending a wanderer unlocks companion follow AI, distinct passive squad buffs, and active tactical assistance in combat.

### 🎮 Steam Deck & Controller Polish
- **Twin-Stick Aiming Preset:** Reworked the default Steam Deck configuration to use the right joystick for independent 360° tactical aiming and menu pointer control.
- **7 Bundled Steam Input Configurations:** Generated and packaged native Steam Input controller profiles with updated glyph mappings and tactile feedback.

### 👥 Multiplayer Deployment Briefing & Synchronized Launch Gate
- **Squad Deployment Briefing Screen:** Pre-match staging interface displaying squad roster, player callsigns, equipped class chassis, and synced loadout summaries.
- **Synchronized Ready-Up Gate:** Host-initiated countdown requires 100% room ready status; automatically aborts if a player unreadies or disconnects mid-countdown.
- **Deterministic Network Seeds:** Synchronized world seed delivery across all connected clients ensuring identical chunk topography and deterministic enemy spawn IDs.

### ⚡ Engine Diagnostics, GPU Budgets & Mid-Run Crash Recovery
- **Mid-Run Process Recovery:** Implemented `runCheckpoint.js` crash-recovery checkpoints, allowing players to resume in-progress expeditions after unexpected process termination.
- **Hardware Performance Diagnostics:** Integrated `gpuFrameTimer.js` and `gpuMemoryBudget.js` for safe real-time GPU frame profiling, memory tier gating, and asset telemetry.
- **8 Transformative Relics Complete:** Finalized the transformative relic catalog with the addition of **Queen's Milk**, **Scrap Cycler**, and **Vesper Doctrine**.
- **Depth Contract Scaling:** Implemented per-ring salvage multipliers and dynamic director aggression scaling across the outer sectors.

### 📖 Biomechanical Horror Aesthetic Constitution & Production Backlog
- Established `docs/3d-asset-master-backlog-and-prompts.md` defining the dark H.R. Giger × Event Horizon aesthetic constitution and production-ready generation prompts for all remaining game objects, enemies, and environmental scatter.

---

## 🛠️ Fixes & Stability

- Fixed ESLint warnings and CodeQL unused import alerts across JavaScript modules and Blender Python conversion scripts.
- Adjusted the public retail asset budget ceiling to 2,700 MiB to accommodate the expanded 3D runtime payload.
- Fixed 3D model loading failures in packaged Electron builds via `asarUnpack`.
- Resolved mouse-focus dragging issues and trigger selection in the Armory UI.
- Restored Overclock bays A & B with query-selector dataset guards.
- Protected room transitions and stabilized canyon map state during rapid zone crossings.
- Resolved race conditions in relic cache opening animations and season pass XP collection toasts.

## 📦 Upgrade Notes

- Retail asset manifests (`steam/referenced-assets.json` and `steam/retail-asset-report.json`) have been updated to reflect the new 3D model catalog.
- Run `npm run presubmit` to verify local asset integrity, dependency trees, and audio manifests before building.
- Packaged builds for Linux and Windows include unpacked 3D models in `app.asar.unpacked/public/3d/runtime/`.
