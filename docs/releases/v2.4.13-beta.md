## 2. The unified Foundry

- **One item catalog** (`src/data/itemCatalog.js`): every item shows the same name,
  rarity and icon in the Armory, Foundry, hero screen and Vault. It's checked per id,
  per surface, in three locales.
- **The Foundry hub**, on by default: Stash / Loadout / Fabricate / Trade-up / Store in
  one window. It is class-themed and controller-complete, and a failed tab can't strand
  it. `hb_foundry_hub=0` opts out.
- **Trade-ups that stick:**
  - the local ledger commits in one write;
  - on Steam the server picks the inputs, consumes them, grants the result and
    refunds on any failure;
  - trades stay within the Season 0 collection, so keys, shards and trophies are
    never burned.
- **Fair Foundry odds**, 30/24/32/11/3: an empty tier gets no weight, and the odds are
  shown before you roll. Foundry guns show their real combat multipliers.
- **Class sync:** the loadout follows the class being played, so a fabricated gun
  always reaches combat.
