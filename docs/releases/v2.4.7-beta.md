## 1. Localization — Both Axes at Zero

The `v2.4.4-beta` sweep took runtime strings to zero but left 52 markup strings unannotated. Those are now closed, and the content catalogs are fully translated.

- **0 unannotated markup, 0 unlocalized runtime strings.** 1,898 keys per locale across all 7 languages at exact parity — zero missing, zero extra. Narrative catalog 100% translated in every locale.
- **The last 52 were mixed-content elements**: loose text sitting beside a child element. `applyStaticTranslations` assigns `textContent`, so annotating them would have deleted their children. Each loose text node now has its own span — the Steam Vault header, chips and tabs, the multiplayer title and hint row, the fabrication and pickup-counter resource chips, the three confirm dialogs (text split across `<br>`), the controls hints, and the `TITLE // ACCENT` headers across about/codex/achievements/vault/dossier.
- **Content catalogs wired**: the 121-item Steam catalog and 30 community skins now route through `localizeCatalog`, with identifier fields (itemdefid, rarity, tradable/marketable flags, asset URLs) protected by skip lists. `steamItemCatalog.js` is generated, so the wrapper lives in `scripts/build-steam-item-catalog.js`.
- **`alt` is translatable.** The engine handled only `title`/`aria-label`/`placeholder`, so six static alt texts could not be localized at all — a screen reader announced "Crashed ship" mid-cutscene in every locale.
- **The loading screen** was entirely English: `main.js` routes it through `renderLoaderLogs()` and a 31-branch asset-message lookup, neither of which is an assignment the scanner recognised.

### One deliberate visual change

The pickup-counter rows styled their count cell with `.pickup-counter-panel__row span:last-child` — a *descendant* selector, so it also matched the icon span, which is the last element child of the label. Wrapping the label text would have handed that styling to the new span. The four rules are now scoped to direct children, which is what a right-aligned tabular-number rule always meant. The icon consequently falls back to its own authored colour: it rendered `rgba(255,228,172,.95)` by specificity accident and now renders the `rgba(255,199,99,.96)` its own rule specifies. Confirmed by reading computed styles in the built page.

### A gap only the browser could show

`updateDetailsPanel()` returned early on a missing item and was never called for an empty vault, so a player with no items read the Steam Vault detail panel in English in every locale. A `data-i18n` annotation would have been the wrong fix — once an item is selected those same elements hold its catalog name, which a locale change would then overwrite with the placeholder. JS owns both states now, covered by `src/steamVaultDetails.test.js`.

### Coverage ratchet

`npm run i18n:audit` reports the three failure modes; `scripts/audit-i18n.test.js` ratchets them **per screen and per module** against `docs/reports/i18n-coverage-baseline.json`. Counts may fall, never rise. Six scanner defects were found and fixed while closing the gap, each of which had been hiding live text — a leading `/` read as a path (hiding the `// ACCENT` headers), a leading `>` read as markup (hiding the loader's prompt-prefixed lines), letter and length tests running on the raw literal instead of the visible text, and unrecognised text-setting helpers (`setTxt`, `renderLoaderLogs`) plus elements reached by class selector rather than id.

## Known gaps

- **No native-speaker review.** Every non-English string in the catalog is machine-authored. Linguistic review across the six non-English locales remains open.
- **Two Steamworks item descriptions carry developer notes in their English source.** `steam/inventory_schema_hunker_bunker.json` has internal notes pasted into the player-facing descriptions for itemdef 4110 and the earned Cache Key, citing source paths, itemdef numbers and internal doc sections. That schema is what uploads to Steamworks, so the notes will appear on those items' store pages. The six non-English locales carry only the real product sentence; the English source is deliberately left as-authored so the defect stays visible. Fixing shipped store copy is a content decision.
- **`boot-and-menu.spec.js` gameplay-entry flakiness** is unresolved and pre-dates this release.
