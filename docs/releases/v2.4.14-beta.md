Branch: `dev/sprint-49` · 2026-10-01

Sprint 49, first slice: **finish the features the Steam review asked for, and fix what the 2026-09-30 co-op playtest found.**

- **Filtered player chat.** Co-op and PvP rooms have real text chat. It goes through the relay and a seven-language filter, and has mute, block and report.
- **Developer commentary.** The commentary now tells the real history of the game, with dates you can check, in all seven languages.

- **Co-op.** Enemies attacking your squadmate no longer take your hearts. A lobby now refuses a player on a different build, and says which builds.

## 1. Filtered player chat (S49-02, S49-03, S49-04)

| Part | What ships |
| :--- | :--- |
| Transport (`e8cc0a16`) | Authenticated, room-scoped chat through the relay. The server assigns sender identity and message IDs; a third room receives nothing. Rate limits, bounded Unicode text and nonce-based deduplication. |
| Filter (`e8cc0a16`) | `src/chatFilter.js` with `src/data/chatFilterTerms.js`: a curated baseline for English, German, Latin American Spanish, Japanese, Brazilian Portuguese, Russian and Simplified Chinese. Unsupported scripts and control characters fail closed. It is a baseline, not a guarantee. |
| Player flow (`82501e4f`) | Chat in the lobby, the field HUD and Settings: one room channel shared between lobby and mission (PvP opponents can read it, and the panel says so); 50-message history, timestamps, unread state, quick messages, explicit send errors, stable retry nonce. Mute (one-way), block (both ways), undo and reasoned reports. Plain-text rendering only. Controller and on-screen keyboard entry, with IME-safe Enter. Seven locales. |

## 2. Steam review follow-through (S49-06, S49-10, S49-11)

### Developer commentary

- **Real history (`7f0e6f1d`).** Ten entries were rewritten from design slogans into dated history taken from this repository and its tests. Examples: O2 and banking arriving in one commit (28 May 2026); the 29 May authored room templates; the September co-op playtest that made black boxes owned; the Queen's three phases and weakpoint windows; the six-day leaderboard outage and the contract test it produced.
- **Seven languages (`3c68c914`).** `COMMENTARY_ENTRIES` is a `localizeCatalog('narrative.commentary')` catalog, so English in `main.js` stays the source and the 12 entries are translated into de, es-419, pt-BR, ja, ru and zh-CN. The "commentary on" card now names the real route: Settings → Audio → Developer Commentary → Read All.

### Controller journey

`tests/e2e/probes/controller-journey.spec.js` (`0e7bba0c`, `82b04e7b`, `7e31a8e9`) drives every review surface using only controller menu events. It covers the Vault and Foundry hub (every tab), the Content Guide (reach, reader, scroll, back twice), commentary READ ALL, the multiplayer console, an Armory slot picker, Archive, Codex, Dossier, the title Quit prompt, and in-run pause → abort → results. It found:

| Bug | Fix |
| :--- | :--- |
| With the Content Guide open over Settings, the D-pad moved through Settings behind it: the first open root in `MENU_FOCUS_ROOT_IDS` wins, and Settings came first | Every surface opened from Settings precedes it, and a test pins the order (`228936b8`) |
| One Back from the Content Guide closed the guide **and** Settings | The Settings branch of Escape closes only a surface drawn above it (`f4a61dfa`) |
| Closing the Foundry hub left focus on a bare `<div>` | The hub returns focus to whatever opened it (`e12b4beb`) |
| A stationary mouse stole controller focus whenever a modal closed (`pointerover` re-fires under an unmoved pointer) | Hover sync is skipped in controller mode (`a9c8613b`). A wider guard for mouse mode (`0869c05f`) broke D-pad scrolling of Achievements and was reverted (`062ab937`); see Known issues |
| Closing the guide's dialogue reader left focus on nothing | The reader returns focus to the button that opened it (`ae1dd80c`) |
| The Content Guide row was stranded under the CONTROLS tab | It sits under ACCESSIBILITY, beside the Gore toggle; the reviewer access text names the tab (`a73f5a06`) |

### Mature content

- **Cinematics in the Steam build (`0b0a8d83`).** VIEW CINEMATIC / VIEW ENDING set a root-absolute `/cutscenes/…` path. Under the packaged `file://` build that points at the drive root, so reviewers silently got a text fallback. `endingCutsceneSources()` resolves through `assetUrl` and is shared with the progression walkthrough.
- **Same scene as in play (`251c6864`).** The reader shows each dialogue node's still above its text, as the game plays it (18 stills, all present). The transcript text is unchanged.
- **No drift (`f940f01a`).** `LORE_LOGS` is exported, and a test pins the guide's C11/B03 letters to the in-game text word for word.
- **Readable close (`ae1dd80c`).** The reader's "× CLOSE SCENE VIEWER" button no longer overflows `.close-modal`'s fixed square.

## 3. Purchases and the store (S49-07, S49-08)

| Commit | Change |
| :--- | :--- |
| `58b115d7` | `src/steamStoreCatalog.js`: one authoritative catalog adapter for quantities and prices; Vault reconciliation; the public USD MicroTxn catalog is no longer shown as a quote for Steam's hosted Item Store, which shows its own account-currency total at checkout. |
| `07f86986` | Reconciliation stops reporting false success. A finalized payment with a pending grant is `paidNotGranted`; completed local purchases missing from the report make the run unhealthy; conflicting identifiers, unknown Steam states and grants without settled payment become `needsReview`; refunds cannot hide behind a later `reversed` status. |
| `6d871747` | Complete, restart-safe enumeration: continue past short batches, deduplicate by transaction, stop only on an empty batch, persist each batch's cursor with its evidence. JSON and SQLite paginate beyond 1,000 purchases and store checkpoints atomically (new `microtxn_checkpoints` table, created if missing). The CLI keeps every page of reviewer evidence. `HB_STEAM_REPORT_START_TIME` initializes a new stream; see the [runbook](../steam-backend-admin-runbook.md#durable-getreport-reconciliation). |
| `063db076` | Inventory grants follow Steam's real `AddItem` contract: read `item_json`, send one repeated itemdef per instance, and reject empty or rejected HTTP-200 bodies instead of counting them as delivered. |
| `c7f0cf8c` | Paid grants are durable and idempotent. A stable uint64 request ID and immutable order snapshot are persisted before `AddItem`. Concurrent finalize calls are serialized, retries recheck `QueryTxn`, and a lost response or a crash reuses the same ID. Ambiguous legacy attempts are held for review instead of re-granted. |

The reconciliation worker is still read-only. It finds problems but does not repair them; unattended paid recovery and reversal dispositions remain open in S49-08.

## 4. Co-op (QA 2026-09-30)

The [playtest analysis](../planning/qa-2026-09-30-deck-pc-coop-session.md) read both session logs. The Deck ran 2.4.9 against a 2.4.13 host, which explained most of the strange behaviour.

- **Enemies on a squadmate hurt you (`1334b1e1`).** A cryosnail chewing on the partner's body took the host's three hearts from about 102 m away. `selectSnailTarget` kept downed squadmates as targets, and the attack branch called `takeDamage` for any `player` target. Remote targets are no longer damaged or slowed locally, since their own client owns their HP, and downed squadmates are not targets.
- **Build gate (`1334b1e1`).** Joins carry `buildVersion`, and the relay locks a room to its host's build. A different build is rejected with `build_mismatch`, and a seven-language toast names both builds. Clients from before this release send no build, so they still match each other.

## 5. World, audio and telemetry

- **Biome flicker (`b388698f`).** Walking the cryo/bio line flipped the player's sector five times in 2.5 minutes. The player's sector now changes only 4 units past the line, while world generation keeps the raw thresholds.
- **Draw-call telemetry (`35cdecc5`).** Session logs reported 1 draw call and 1 triangle in gameplay, because three.js resets `renderer.info` on every composer pass. The counters are now reset once per frame, so S49-31's draw-call budget is measurable. Rendering is unchanged.
- **Audio (`5e3510ca`).** Every OST track is triggered in context, including dedicated boss tracks (25–31) with on-demand decode. Subtle enemy movement and impact sounds use 14 new `audio/enemies/*.ogg` files, with stereo panning and filtering when the context supports them.
- **Sporesnail facing (`63fcc797`).** The 3D sporesnail faces along its movement instead of backwards.

## 6. Backend deploy and release tooling

- **Image contents (`7783278f`).** Deploying `6d871747` crash-looped production with `ERR_MODULE_NOT_FOUND /app/src/chatFilter.js`, because `deploy/Dockerfile` copied only `server/`. The image now includes the chat filter. `server/deployImageContents.test.js` walks the import graph the container runs and fails if the image lacks a file, or a package isn't a production dependency.
- **Deploy procedure.** The deploy build no longer uses the live working tree, which can hold other contributors' uncommitted work. The candidate image is built from a clean git worktree, smoke-run with dummy configuration (health, the relay build gate, chat delivery with filtering), and switched in by `~/server/deploy-backend.sh`, which rolls back to a pre-built image if the candidate is not healthy within two minutes. Production runs `7783278f`.
- **Steam upload blocker (`35797620`).** A stray symlink, `public/audio/ost/Kaelens Sleeping Machine.mp3`, failed soundtrack packaging as an unlisted 44th MP3; nothing loaded it. Removed, and the retail asset reports were regenerated for the new enemy sounds.
