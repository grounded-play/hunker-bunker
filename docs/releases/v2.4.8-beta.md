## 1. Armory UI Scaling & Layout Standards

- **Standard Token Scaling**: Replaced legacy and hardcoded pixel clamps (`clamp(6px, .48vw, 8px)`, `clamp(8px, .67vw, 11px)`, `font-size: 7px`) with the engine's responsive units (`--vu`, `--vu-text`, and `--font-*`). Typography and slot heights scale proportionately across every resolution from 1280x800 (Steam Deck) through 4K (3840x2160), restoring readability without microscopic text.
- **Scrollbar Elimination**: Re-architected `.armory-controls-sidebar` and `.armory-panel` to use proportional `--vu` paddings and vertical flow. Even on compact displays (800px vertical), content fits comfortably with >150px safety headroom, ensuring `scrollHeight <= clientHeight` with `scrollbar-width: none` and `overflow: hidden !important`.
- **Eliminated Overlaps**:
  - **Live Stage Preview (`.armory-stage-readout`)**: Relocated from a floating absolute pixel position (which collided with the floating 3D weapon model in upper-center space) into a dedicated bottom-right anchor in `.armory-stage-column`, resting cleanly below the weapon and clear of the operator platform.
  - **Exosuit Rig Alignment**: Set `align-items: start` on `.bench-row-two-col` and normalized `.armory-slot` heights so that the live HUD theme preview does not stretch or deform the neighboring Alt Radio Voice Bank slot.

---

## 2. Universal Top-Right Settings Anchor

- **Exact Position Parity**: Standardized the corner settings button anchor across all screens (`#menu`, `#armory-screen`, and `#ui`) using unified CSS variables:
  - `--corner-settings-top: calc(var(--vu) * 1.8)`
  - `--corner-settings-right: calc(var(--vu) * 2.4)`
  - `--corner-settings-size: calc(var(--vu) * 4.4)`
- **Armory Screen Integration**: Moved `#armory-settings-btn` out of the dense `.armory-operator-status` class-tab bar and into a dedicated `.armory-corner-settings` container. The gear button now appears at the exact same pixel coordinates on every screen in the game.
