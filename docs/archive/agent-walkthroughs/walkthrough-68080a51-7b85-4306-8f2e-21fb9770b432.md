# Universal Turn-Based Encounter System Walkthrough

## Summary of Accomplishments

We expanded the turn-based Earthbound/Pokemon interaction system to encompass **all wild enemy archetypes** (Crawlers, Sentinels, Bio Chargers, Alien Protos, Spore Mortars, Mycelium Stalkers) as well as **Camp Leaders & turned NPCs** (Commander Martha, Overseer Kaelen, Chief Briggs, Dr. Okonkwo-Vass, and Hive Elders: Nahl, Vey, Rhun).

---

## Key Features Implemented

1. **Universal State Machine ([universalEncounter.js](file:///home/caveman/Desktop/icecave/hunker-bunker/src/universalEncounter.js))**:
   - Categorizes encounter entities into:
     - **Snails**: `FIGHT`, `TALK` (Befriend), `FLEE`.
     - **Biological Hostiles** (Crawlers, Alien Protos, Bio Chargers): `FIGHT`, `PACIFY`, `FLEE`.
     - **Mechanical Hostiles** (Sentinels, Drones): `FIGHT`, `HACK`, `FLEE`.
     - **Camp Leaders / NPCs** (Martha, Kaelen, Briggs, Dr. Okonkwo-Vass): `DUEL`, `TALK` (Dialogue Beats), `RECRUIT`, `LEAVE`.
     - **Hive Elders** (Nahl, Vey, Rhun): `COMMUNE`, `TALK`, `BOND`, `LEAVE`.

2. **Dynamic UI & Asset Mapping ([index.html](file:///home/caveman/Desktop/icecave/hunker-bunker/index.html) & [style.css](file:///home/caveman/Desktop/icecave/hunker-bunker/style.css))**:
   - Added `#snail-encounter-custom-btn` to support context actions like `RECRUIT`, `BOND`, and `TRADE`.
   - Dynamically populates action button labels based on entity category (`PACIFY`, `HACK`, `COMMUNE`, etc.).
   - Full portrait mapping for Camp Leaders (`/martha_camp_walk_v2.png`, `/kaelen_camp_walk_v2.png`, `/briggs_camp_walk_v2.png`, `/civilian_researcher_walk.png`, `/alien_nahl_walk.png`) and wild enemies (`/alien_proto_crawler_walk.png`, `/bio_charger.png`, etc.).

3. **Game & Dialogue Integration ([threeGame.js](file:///home/caveman/Desktop/icecave/hunker-bunker/src/threeGame.js))**:
   - Wild enemy proximity contact in Act 2 triggers `openUniversalEncounter` with retro canvas dissolve transitions.
   - `talkToLeader` launches the retro transition view and populates dialogue beats into the stage log.
