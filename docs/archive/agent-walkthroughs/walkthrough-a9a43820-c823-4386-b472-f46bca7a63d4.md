# Walkthrough - Dynamic Door transitions in Hunker Bunker

We have successfully replaced the random, round-robin door image rotation in Hunker Bunker with a context-aware system where transitions use doors based on character class selection, victories, defeats, and main menu contexts.

## Changes Made

### [main.js](file:///home/caveman/Desktop/icecave/hunker-bunker/main.js)
1. **Removed Random Iteration**:
   - Removed `DOOR_IMAGES`, `currentDoorIndex`, and `getNextDoorImage()`.
2. **Created `getDoorImage(key)`**:
   - Mapped dynamic categories to paths:
     - `SCOUT` -> `/door_bio.png` (Spore/bio)
     - `TANK` -> `/door_nuclear.png` (Hazard/nuclear)
     - `ENGINEER` -> `/door_cryo.png` (Frost/cryo)
     - `base` -> `/door.webp` (Default base bulkhead door)
     - `win` -> `/door_alien.png` (Advanced/clean victory door)
     - `lose` -> `/door_rust.png` (Rusted/ruined failure door)
   - Auto-resolved empty/null keys to the active character class.
3. **Updated `triggerDoorTransition`**:
   - Accepts a new parameter `doorKey`.
   - Resolves and sets `--door-bg-image` dynamically using `getDoorImage(doorKey)`.
4. **Updated Character Preview Swap (`triggerHeroPreviewSwap`)**:
   - Selects the target class door during roster card transitions.
5. **Integrated Win and Lose Outcomes**:
   - Upon player death (`runDeathSequence`), a door transition with `'lose'` is triggered before transitioning to the game over screen.
   - Upon victory / extraction (`player-extracted`), a door transition with `'win'` is triggered before transitioning to the game over screen.
6. **Main Menu / Back-to-Menu Transitions**:
   - Configured all main menu entries and exits to use the `'base'` door.

## Testing & Validation

### Automated Tests
- Ran standard unit tests via `npm run test` (8 test suites, 68 tests), which passed successfully.
- Ran linter via `npm run lint`, which reported 0 syntax or styling errors.

### Manual Behavior Verification
- **Lobby Class Selection**: Clicking Scout, Tank, and Engineer cards correctly closes and opens the class preview panel using the corresponding class-themed door:
  - Scout -> Bio green spore door (`/door_bio.png`)
  - Tank -> Nuclear hazardous orange door (`/door_nuclear.png`)
  - Engineer -> Cryo frosty blue door (`/door_cryo.png`)
- **Main Menu Entries**: Initial entry and returns to the main menu use the base industrial bulkhead door (`/door.webp`).
- **Gameplay Entrance**: Transitioning to gameplay uses the selected class's door.
- **Failures / Deaths**: Game over transition uses the rusted, broken bulkhead door (`/door_rust.png`).
- **Victories**: Extraction complete transition uses the clean, advanced alien door (`/door_alien.png`).
