# Black Box Marquee Walkthrough

The "last contractor" UI in the hero select screen has been updated to display as a single scrolling line (marquee) rather than a multi-line stacked list.

## Changes Made

- **main.js**: Updated `refreshLastContractor()` to wrap the black box archive items in a `<div class="last-contractor-marquee">` container, separating each log with `///` instead of a `<br>` tag.
- **style.css**: 
  - Adjusted the `.last-contractor` container to a single-line layout (`white-space: nowrap`) and changed its alignment.
  - Added `.last-contractor-marquee` which uses a CSS `@keyframes` animation to continually scroll the text horizontally from right to left.
  - The pulsing animation on the container borders remains intact.

## Testing
- Ensure you have played a run and died (or you have a black box record).
- Return to the hero select screen.
- Observe the scrolling marquee at the bottom of the screen showing your past black box records.
