# Walkthrough: Wall Damage Colors, Scanner Alien Display Fix & Hole Filling

Implemented three key visual and gameplay improvements in Hunker Bunker:

## Changes Made

### 1. Wall Damage Color & Emissive Shifting
- **File**: [threeGame.js](file:///home/caveman/Desktop/icecave/hunker-bunker/src/threeGame.js#L13535-L13565)
- Added `updateWallDamageColor(wall)` helper:
  - Calculates damage ratio `1 - (hp / maxHp)`.
  - Clones shared material on first damage so each damaged wall has individual visual state.
  - Interpolates `.color` from standard metal/grey towards glowing ember red-orange (`#ff3300`).
  - Sets `.emissive` to `#ff2200` with `.emissiveIntensity` scaling up to `0.85` as HP drops.

### 2. Scanner Alien Visual Display Fix
- **File**: [threeGame.js](file:///home/caveman/Desktop/icecave/hunker-bunker/src/threeGame.js#L10565-L10577) & [threeGame.js](file:///home/caveman/Desktop/icecave/hunker-bunker/src/threeGame.js#L10755)
- Updated `spawnEnemyXrayGhost`:
  - Defaults X-ray ghost sprite tint to the creature's natural sprite color (`0xffffff`) instead of forcing `RADAR_DANGER_COLOR` (`#ff3344` red).
  - Preserves normal live alien textures and states during scans while keeping the danger ping marker ring overhead red.

### 3. Hole Filling Mechanics & HUD Prompt
- **Files**: [index.html](file:///home/caveman/Desktop/icecave/hunker-bunker/index.html#L860-L865) and [threeGame.js](file:///home/caveman/Desktop/icecave/hunker-bunker/src/threeGame.js#L17927-L18070)
- Added `#hole-hud-prompt` in `index.html` displaying `PRESS [E] FILL HOLE`.
- Added `this.filledHoleKeys = new Set()` in `ThreeGame`.
- Updated `getHoleVisualInfo` and `mountChunk` to treat filled holes as safe ground tiles and render a ground patch.
- Added `fillHoleAt(worldX, worldZ)`:
  - Replaces hole visual mesh with a ground floor patch.
  - Triggers gravel/dust particle burst FX and sound feedback.
  - Spawns a floating `SEALED` feedback pip.
- Added `interactWithHoleTile()` and hooked it into the interact action chain (`[E]` key / gamepad interact).
