# Walkthrough: Objective-Based RGB Chapter Unlocks & Choice Carry-Over System

We have implemented an objective-based unlock and progression system that bridges Survivor Camps, Alien Hives, and the RGB Archive Simulation mini-game.

## Summary of Accomplishments

### 1. Objective-Based Camp Sub-Missions & Hive Integration
- **Camp Primary Mission Gate:** Completing a Survivor Camp's primary required mission (e.g. *Reactor Venting* at Camp Meridian, *Spore Cleansing* at Camp Tallow, *Armory Breach* at Camp Vesper) now unlocks a specialized **Archive Sub-Mission** (*HIVE ARCHIVE CH. N*).
- **Hive Archive Terminal Objective:** Accepting an Archive Sub-Mission sets a HUD objective and points the compass to an Archive Terminal near an Alien Hive.
- **Archive Recovery & Event Dispatch:** Interacting with the Hive Archive Terminal completes the sub-mission, dispatches `rgb-chapter-archive-recovered`, and unlocks the corresponding RGB chapter (e.g., Chapter 1: *Parking Lot*, Chapter 2: *Warehouse*, Chapter 3: *Incident Review*).

### 2. RGB Save Schema & Chapter Selection
- Extended the `hb_minigame_rgb_v1` save record to support:
  - `unlockedChapters: string[]` to track unlocked chapters.
  - `chapterSnapshots: Record<string, RunState>` to capture the narrative choices made up to each chapter's entrance.
- Added helpers `unlockChapter`, `isChapterUnlocked`, `saveChapterSnapshot`, and `getChapterSnapshot`.
- Enhanced the title screen `ARCHIVE SIMULATOR` modal to display chapter cards with interactive unlock statuses and chapter select buttons.

### 3. Narrative Choice Carry-Over & Run Locking
- **Choice Carry-Over:** When advancing chapters during an RGB run (Chapters 1 → 6), all `runState` choices (`flags`, `evidence`, `inventory`, `pain`, `timeBand`, `trust4A`, `calibrationQuality`, `routeHistory`) are seamlessly preserved into subsequent chapters.
- **Run Choice Locking:** Mid-run choices cannot be reversed. Reloading from a chapter checkpoint restores the choice snapshot captured at that chapter's entry.
