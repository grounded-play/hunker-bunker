# Walkthrough — Sprint 2A Dungeon Pivot & Bunker Director Integration

This walkthrough details the changes made to complete the First-Person Procedural Dungeon pivot, the integration of the watchful **Bunker Director**, and the git branch configuration.

## Changes Made

### Core Mechanics & Fixes
* **SnailEnemy NavMesh Fix**: Modified [SnailEnemy.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Scripts/Core/SnailEnemy.cs) to check `isOnNavMesh` before querying `remainingDistance`. This prevents null reference exceptions when enemies are not on the NavMesh.
* **Aggro Control**: Made `SetAggro(bool)` in [EnemyBase.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Scripts/Core/EnemyBase.cs) public so the director can force aggro on newly spawned patrols.
* **Map Blackout**: Added `BlackoutActive` to [MapGenerator.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Scripts/Core/MapGenerator.cs) which dims all room lights to zero when active.
* **Minimap Corruption**: Added `IsCorrupted` to [MinimapController.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Scripts/Core/MinimapController.cs) which scrambles telemetry text and jitters map markers in real-time.

### Watchful Bunker Director
* **Bunker Director Brain**: Implemented [BunkerDirector.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Scripts/Core/BunkerDirector.cs) to track vitals (HP/O2 ratios, depth, safe zone status, class-specific noise penalties) and trigger adaptive gameplay actions:
  * **Patrol surge**: Spawns 1-2 Cybersnails near the player in connected rooms and sets their aggro to true.
  * **Lights out**: Dims the procedural room lighting for 6 seconds.
  * **Minimap corruption**: Jitters markers and scrambles navigation readout for 18 seconds.
  * **Mercy salvage**: Spawns health, O2, or scrap pickups directly in front of a struggling player.
  * **Transmission taunts**: Displays ominous typewriter transmissions on the HUD.
* **GameSceneManager Integration**: Wired director tick and actions into [GameSceneManager.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Scripts/Core/GameSceneManager.cs).

### Scene Build Automation
* **Dungeon Builder Pivot**: Updated [GameSceneBuilder.cs](file:///home/caveman/Desktop/icecave/stalkpit/StalkPit/Assets/Editor/GameSceneBuilder.cs) to construct the First-Person Procedural Dungeon scene (`MapGenerator`, templates, Vitials HUD, player rigs) instead of the planet surface world.

## Git Branch Setup & Switching

We created a new branch called `sprint-2` based on the latest merged changes on `origin/mothership` (which contains all these dungeon pivot features).

### This Computer
This computer has already been set up on the new branch:
```bash
git checkout -b sprint-2 origin/mothership
git push -u origin sprint-2
```

### Other Computer
To check out the code on your other computer, run the following commands in the other computer's terminal:
```bash
git fetch origin
git checkout sprint-2
```
This will download and switch the other computer to the exact same state, tracking the `sprint-2` branch!
