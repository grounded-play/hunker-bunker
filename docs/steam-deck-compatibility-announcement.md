# Steam Announcement: Hunker Bunker — Steam Deck & Controller Compatibility Support

## Steamworks Event Fields

**Subtitle:** Steam Deck-ready controls, readable 16:10 UI, Steam Input glyphs, and controller-first bunker runs.

**Summary:** Hunker Bunker is built for handheld operators: Steam Input actions, controller-aware prompts, Deck-friendly layouts, and Steam Cloud progress.

**Cover image:** `steam/store/steam_deck_compatibility_event_header_en.png` — 1920 x 622.

We are excited to share details about **Hunker Bunker’s** Steam Deck and hardware compatibility! From day one, our design philosophy has been to ensure that descending into the bunker feels native, responsive, and fully optimized for handheld operators.

Here is a breakdown of what you can expect when playing Hunker Bunker on the Steam Deck and other controller-based hardware.

---

## 🎮 Full Steam Input & Controller Support

Hunker Bunker is fully integrated with **Steam Input**, providing native controller layouts out-of-the-box. There is no need for mouse or keyboard emulation.

*   **Native Action Mapping:** Move, aim, fire your sidearm, trigger radar scans, reload, use class-specific abilities, and pause/resume menus with physical buttons.
*   **Dynamic UI Glyphs:** The UI automatically detects your controller type and instantly swaps input prompts to display native Steam Deck/Xbox/PlayStation buttons.
*   **Full Menu Navigation:** Every in-game terminal, the Bunker Tree (Class Skills), the Archive reader, and the Steam Vault cosmetic viewer are fully traversable using the D-pad, analog sticks, and face buttons.

---

## ⌨️ Touchscreen & Virtual Keyboard Integration

For text entry (such as entering seed overrides or operator names), Hunker Bunker leverages Steam's native overlay:
*   The game automatically invokes the **Steam Virtual Keyboard Overlay** whenever a text field is selected.
*   Supports standard Steam Deck touchscreen interactions for HUD and menu selections.

---

## ⚙️ Steam Deck Performance & Specs

*   **Framerate Target:** Optimized to run at a locked **60 FPS** on the default Steam Deck hardware profile.
*   **Aspect Ratio Support:** Supports the native Steam Deck **16:10 aspect ratio (1280x800)** layout seamlessly, keeping HUD elements readable and safely within the boundary zones.
*   **Power Optimization:** Engineered to minimize CPU/GPU overhead, maximizing battery life for longer offline runs.

---

## 🐧 Recommended Proton/Linux Runtime

Hunker Bunker is distributed as a packaged Windows binary that runs seamlessly under Valve's **Proton** compatibility layer. 
*   **Tested Runtime:** Officially tested and optimized on **Proton 9.0 (Stable)**.
*   **Steam Cloud Support:** Your local progress, settings, and run history are fully synchronized between your desktop PC and your Steam Deck via **Steam Cloud**.

We are committed to delivering a stellar handheld experience. See you in the depths, operator!
