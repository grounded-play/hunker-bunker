# Controls

Surviving the depths of the icecave requires mastering your exosuit.

| Action | Keybinding |
| --- | --- |
| **Move Up** | `W` or `ArrowUp` |
| **Move Down** | `S` or `ArrowDown` |
| **Move Left** | `A` or `ArrowLeft` |
| **Move Right** | `D` or `ArrowRight` |
| **Interact** | `E` |
| **Reload** | `R` |
| **Class Ability** | `F` |
| **Radar Scan** | `Q` |
| **Sprint** | `Shift` |

> [!TIP]
> You can remap these controls at any time from the in-game settings menu!
