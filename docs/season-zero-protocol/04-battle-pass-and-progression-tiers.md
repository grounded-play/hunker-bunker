# Season 0: Tactical Battle Pass & Progression Tiers

## 1. Overview & Pass Mechanics
The **Season 0 Tactical Dossier (Battle Pass)** is a 50-tier progression track that rewards players for exploring the subterranean depths, completing combat runs, and eliminating sector bosses.

### Core Philosophy
- **Generous Free Track**: 20 of the 50 tiers feature valuable Free rewards (Deep Relic Caches, Reagents, Base Decals, and Tactical Tokens).
- **Classified Dossier Pass ($7.99 or Steam Store direct)**: Unlocks access to all 50 premium tier rewards, including exclusive Legendary Skins, Weapon Charms, Rig Overclocks, and Relic Keys.
- **No FOMO / Expiration Lockout**: Once unlocked, players can continue progressing their active season pass even after future seasons launch (Helldivers 2 Warbond model).

---

## 2. XP Pacing & Leveling Curve

### Progression Parameters
- **XP Per Tier**: Flat **5,000 XP** per tier (50 Tiers × 5,000 XP = **250,000 Total XP** for full completion).
- **Estimated Completion Time**: ~25 to 35 hours of active gameplay over a 90-day season.

### XP Earning Sources
| Activity / Milestone | Base XP Awarded | Description |
| :--- | :--- | :--- |
| **Room Cleared** | `+50 XP` | Defeating all enemies in a standard subterranean chamber. |
| **Elite Hive Nest Purged** | `+250 XP` | Destroying a high-threat infested bio-node. |
| **Floor / Sector Cleared** | `+1,000 XP` | Successfully descending through a sub-level transit elevator. |
| **Boss Defeated** | `+2,500 XP` | Terminating Sporesnail, Hive Queen, or Tectonic Golem. |
| **Daily Tactical Bounty** | `+1,500 XP` | Daily objective (e.g., *Freeze 30 enemies with Cryo ammo*). |
| **Weekly Sector Directive** | `+7,500 XP` | Weekly challenge (e.g., *Complete 3 full runs without taking acid damage*). |
