# Trailer fonts

The game's UI faces (loaded from Google Fonts in `index.html`), as static TTFs
so ffmpeg `drawtext` can set trailer text in the game's own type.

- Outfit (Regular, Bold, Black): SIL Open Font License 1.1, https://github.com/google/fonts/tree/main/ofl/outfit
- Space Mono (Regular, Bold): SIL Open Font License 1.1, https://github.com/google/fonts/tree/main/ofl/spacemono

Downloaded from fonts.gstatic.com on 2026-10-14.
